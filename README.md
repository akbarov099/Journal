# Журнал учебного центра

React + Vite (клиент) и Express + MongoDB (сервер).

## Запуск

1. База: нужна запущенная MongoDB.
2. Сервер:

       cd server
       cp .env.example .env     # укажите MONGODB_URI (локальная или Atlas)
       npm install
       npm run dev              # http://localhost:4000/api

3. Клиент (в корне проекта, другой терминал):

       npm install
       npm run dev              # /api проксируется на :4000

Если API на другом адресе, задайте `VITE_API_URL` при сборке клиента.

## Структура
- `server/src` — `models.js` (Group, Student, Record), `routes.js` (REST + архив), `index.js`
- `src/lib` — константы, даты, цвета групп (`colors.js`), API-клиент (`api.js`)
- `src/hooks/useJournal.js` — состояние, оптимистичные обновления, статистика
- `src/components` — Sidebar, GroupHeader, JournalTable, Modal, StudentForm, GroupForm, ArchiveModal, Confirm, Toasts
- `src/styles.css` — стили; цвет группы через CSS-переменные (только светлая тема)

## MongoDB Atlas
- В `server/.env` укажите строку подключения **с именем базы**, например `.../journal?retryWrites=true&w=majority`
  (без имени базы данные попадут в базу `test`).
- В Atlas → Network Access добавьте свой IP, иначе сервер не подключится.
- Логин и пароль храните только в `server/.env` (он в `.gitignore`), не в `.env.example`.

## Время урока
У группы есть поля «Время урока» (начало и конец, например 14:00–15:30). Видно в шапке группы и в плитке слева.
Конец должен быть позже начала; поля можно оставить пустыми.

## Уведомления
Всплывающие сообщения справа внизу: добавлено / изменено / перенесено в архив / восстановлено / удалено навсегда.
Если сервер недоступен — красное сообщение «Нет связи с сервером», а неудавшаяся отметка откатывается.
Уведомления видны и поверх открытых окон (в том числе архива).

## Архив
- Удаление ученика переносит его в архив (отметки и баллы сохраняются). В архиве виден ученик и название его группы.
- Удаление группы переносит в архив всю группу вместе с учениками. Восстановление группы возвращает и её учеников.
- Ученика из архива можно вернуть в его группу (если группа сама в архиве — сначала восстановите группу).
- «Удалить навсегда» — для одной группы / одного ученика (с отметками и баллами).
- «Очистить архив» — полная безвозвратная очистка архива (с подтверждением).

## API архива
| Метод | Путь | Что делает |
|---|---|---|
| DELETE | `/api/groups/:id` | группа (+ ученики) в архив |
| DELETE | `/api/students/:id` | ученик в архив |
| POST | `/api/archive/groups/:id/restore` | восстановить группу с учениками |
| POST | `/api/archive/students/:id/restore` | восстановить ученика |
| DELETE | `/api/archive/groups/:id` | удалить группу навсегда |
| DELETE | `/api/archive/students/:id` | удалить ученика навсегда |
| DELETE | `/api/archive` | очистить архив полностью |

`GET /api/state` возвращает `groups`, `students`, `records` и `archive: { groups, students }`.

## Один сервер для всего
После `npm run build` в корне проекта сервер сам отдаёт папку `dist`, так что достаточно запустить `npm start` в `server/`.
