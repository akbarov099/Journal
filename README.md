# Журнал учебного центра Билим Нуру v2.3

Отдельный фронтенд на React и Vite для API журнала.

## Запуск фронтенда

Папка `Journal` содержит отдельный фронтенд. Запустите свой `JournalServer` на порту 4000, затем в другом терминале откройте папку `Journal` и выполните:

    npm ci
    npm run dev

Vite проксирует `/api` к `http://localhost:4000`. Для другого адреса API укажите `VITE_API_URL` в `.env.local` фронтенда. Значение должно включать путь `/api`. Эту настройку также можно передать при сборке. Учётные данные администратора и MongoDB задаются в `.env` проекта `JournalServer`.

## Сборка для сайта

    npm ci
    npm run build

Раздавайте `Journal/dist` своим веб-сервером. При размещении фронтенда и API на одном домене текущий маршрут `/api` должен вести к `JournalServer`.

## Ссылка для родителей

1. Откройте свою группу и нажмите **Ссылка для родителей → Создать ссылку**.
2. Нажмите **Скопировать ссылку** и отправьте адрес в чат этой группы.
3. Родители открывают страницу без входа в аккаунт и выбирают месяц. В отчёте видны имена, посещаемость и баллы учеников этой группы. Показ фамилий и раздел «Баллы по дням» зависят от данных, которые отдаёт сервер.

Ссылку может открыть любой, у кого она есть. Кнопка **Закрыть доступ** отключает её. После замены ссылки, архивации группы или смены преподавателя предыдущий адрес перестаёт работать. Контакты хранятся в журнале для сотрудников.

После перевода ученика в v2.3 родительский отчёт новой группы показывает записи из новой группы. Если перевод был сделан в более ранней версии, старые оценки могут отображаться в отчёте текущей группы, поскольку у старых записей нет сведений о переводе.

Чтобы родители открывали ссылку вне вашей сети, журнал должен работать на доступном им HTTPS-адресе. Если преподаватели открывают журнал по внутреннему адресу, при сборке задайте `VITE_PUBLIC_JOURNAL_URL` с полным публичным URL этого же журнала. На сервере можно задать `PARENT_LINK_SECRET` как отдельный постоянный случайный секрет. Его смена потребует заново скопировать действующие ссылки.

## Поиск, карточка ученика и занятия на сегодня

- В поиске можно ввести название группы, имя и фамилию ученика в любом порядке или его телефон и телефон родителей. По телефону работает и поиск по части номера. Результаты ограничены группами, доступными текущему аккаунту.
- Нажмите на имя в журнале или в результатах поиска, чтобы открыть карточку ученика с контактами, баллами и посещаемостью по месяцам.
- «Уроки сегодня» использует дату Бишкека. Нажатие на занятие открывает соответствующую группу и дату в журнале.

## Отчёты и синхронизация с Excel

Кнопка «Excel» выгружает `.xlsx` выбранной группы за открытый месяц. В книге два листа: итоги каждого ученика и оценки с посещаемостью по отдельным урокам. За месяц учитываются и сохранённые записи за дни, которые выпали из текущего расписания.

Для обновляемого отчёта откройте «Синхронизация» в нужной группе и создайте ключ. Затем подключите книгу один раз.

1. В Excel выберите **Данные → Получить данные → Из канала OData**. Вставьте адрес из журнала.
2. Выберите **Basic**. Имя пользователя `journal`, пароль — созданный ключ. Если Excel предлагает область действия учётных данных, выберите адрес конкретной группы.
3. Откройте таблицу `Reports` и используйте столбец `month`, чтобы оставить нужный месяц.
4. Команда **Данные → Обновить всё** загружает текущие отметки из журнала. Если в вашей версии Excel в свойствах подключения есть обновление при открытии или по интервалу, включите нужный режим. Импорт и обновление OData поддерживает Excel для Microsoft 365 на Mac. См. [совместимость Power Query](https://support.microsoft.com/en-us/excel/power-query-data-sources-in-excel-versions) и [настройки обновления](https://support.microsoft.com/en-us/excel/refresh-an-external-data-connection-in-excel).

Данные движутся из журнала в Excel. В синхронизацию входят оценки, посещаемость и имена учеников активной группы. Адрес журнала должен быть доступен из Excel. Для подключения по сети используйте HTTPS. У каждого аккаунта свой ключ на группу. Замена или отключение ключа отзывает выданный доступ. Скопируйте ключ при создании, поскольку затем приложение показывает только статус подключения.

## Администратор и преподаватели

- Администратор видит журнал, архив и раздел «Преподаватели». Для каждого преподавателя показано число активных групп и учащихся. Администратор создаёт учётную запись, задаёт пароль и закрепляет преподавателя при создании или редактировании группы.
- Преподаватель входит по номеру телефона и выданному паролю. Он видит свои группы, добавляет учеников, отмечает посещаемость и ставит баллы. Администратор меняет данные учеников, переносит их в другую группу и управляет их архивом. Преподаватель может отправить в архив группу без учеников и истории учеников.
- После обновления v1 используйте прежнюю базу MongoDB. Существующие группы и журналы доступны администратору сразу. Чтобы преподаватель увидел старую группу, назначьте его в настройках группы. При удалении учётной записи группы возвращаются в список без преподавателя.
- Имена групп проверяются при создании и переименовании с учётом архива. Разный регистр или лишние пробелы считаются одним именем. Если в базе v1 уже есть совпадающие имена, администратор может переименовать группы.

## Телефоны и баллы

- Введите 9 цифр номера Кыргызстана. Можно вставить номер с начальным `0` или с кодом `+996`. После форматирования поле выглядит как `+996505 333 233`.
- Оценки за домашнюю и классную работу суммируются по дате записи. Два балла по 4 за один урок дают 8, а итог за выбранный месяц складывается из всех таких записей ученика. Рядом с итогом видны суммы по каждому виду работы.

## Структура

- `src/app` — точка входа, выбор страницы и базовые стили
- `src/pages` — страницы и состояние журнала, включая оптимистичные обновления
- `src/widgets` — таблица журнала, навигация по группам, расписание и преподаватели
- `src/features` — авторизация, поиск, ссылка для родителей, архив, отчёт и синхронизация с Excel
- `src/entities` — группы, ученики и записи журнала
- `src/shared` — API-клиент, общие компоненты и токены оформления. Оформление разделов хранится рядом с компонентами в SCSS
- `shared` — локальные правила телефонов, цветов групп и баллов

## Время урока
У группы есть поля «Время урока» (начало и конец, например 14:00–15:30). Видно в шапке группы и в плитке слева.
Конец должен быть позже начала; поля можно оставить пустыми.

## Уведомления
Всплывающие сообщения справа внизу: добавлено / изменено / перенесено в архив / восстановлено / удалено навсегда.
Если сервер недоступен — красное сообщение «Нет связи с сервером», а неудавшаяся отметка откатывается.
Уведомления видны и поверх открытых окон (в том числе архива).

## Архив
- Удаление ученика переносит его в архив (отметки и баллы сохраняются). В архиве виден ученик и название его группы.
- Удаление группы переносит в архив всю группу вместе с учениками. Восстановление группы возвращает и её учеников.
- Ученика из архива можно вернуть в его группу (если группа сама в архиве — сначала восстановите группу).
- «Удалить навсегда» — для одной группы / одного ученика (с отметками и баллами).
- «Очистить архив» — полная безвозвратная очистка архива (с подтверждением).

## API архива
| Метод | Путь | Что делает |
|---|---|---|
| DELETE | `/api/groups/:id` | группа (+ ученики) в архив |
| DELETE | `/api/students/:id` | ученик в архив |
| POST | `/api/archive/groups/:id/restore` | восстановить группу с учениками |
| POST | `/api/archive/students/:id/restore` | восстановить ученика |
| DELETE | `/api/archive/groups/:id` | удалить группу навсегда |
| DELETE | `/api/archive/students/:id` | удалить ученика навсегда |
| DELETE | `/api/archive` | очистить архив полностью |

`GET /api/state` возвращает `groups`, `students`, `records`, `teachers` и `archive: { groups, students }` в соответствии с ролью. После входа клиент передаёт токен в заголовке `Authorization: Bearer …`.
